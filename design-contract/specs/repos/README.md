# Repository specifications

[REPOSITORIES.md](../../REPOSITORIES.md) maps every repository to its local SPEC.md. [TRACKING.md](../../TRACKING.md) links the published specification and execution issues. Product behavior is governed here by DESIGN.md and specs/visual plus specs/behavior; repository SPEC.md files describe ownership, extraction and delivery acceptance.

Future application implementation scopes are defined in [PLATFORM_PLAN.md](../../PLATFORM_PLAN.md) and the [playback capability contract](../../PLAYBACK_CAPABILITIES.md). Imported playback libraries are foundations, not completed viptv applications.
