# Desktop app (Tauri) — research and decisions

1. Custom title bar: Windows 48 px (search + avatar in it), caption buttons 46 px wide, close hovers system red. Empty space drags; double-click maximises. Snap Layouts need a native hit-test over our maximise button (tauri-plugin-frame snap overlay / decorum). macOS keeps the real traffic lights (titleBarStyle Overlay). Pattern from Spotify / VS Code / Apple TV for Mac: back + forward left, search centred (Ctrl/⌘ K), profile right.
2. Resizing never changes what the app can do, only how much shows (Apple). Navigation is the collapsed icon rail at every width (no expanded sidebar); under 641 it becomes a menu button and the search box becomes an icon. Minimum window ~480 × 360 so snapping works. See the five Home boards: Windows, macOS, 1024, snapped half, 2560 ultrawide.
3. Rows fill the width (more cards, never bigger art); text, settings and history cap at 760–1100 px. Hero and title art is a framed 16:9 card no wider than its source (~774 px) so it is always fully visible and never upscaled; a heavily blurred copy fills the background, where low resolution doesn't show. Past ~1800 px of content the extra width goes to a third hero column instead of bigger art: the Featured queue on Home, Details on title pages (see the ultrawide Home and Series boards); episodes go two-up.
4. Hover card (still image, never video) after ~400 ms rest, gone 500 ms after leaving (NN/g); right-click opens the same menu as '…'; keyboard focus uses :focus-visible rings.
5. Overlays: drawers for sources (video stays visible), flyouts for audio/subs and sort, dialogs only to confirm, info bars for update/offline, toasts with Undo.
6. Player: Space/K, J/L ±10 s, arrows, F, M, C, I, Shift+N; controls hide after ~3 s idle, never while paused; hover scrub thumbnails; the title bar shrinks to drag + caption buttons; mini player = a separate always-on-top 16:9 window; media keys via Media Session / SMTC.
7. Every sign-in method: browser (default, RFC 8252 deep link back), email code, password, another device (QR + code), IPTV provider (Xtream / M3U), or no account. Before a profile is picked the title bar is only the mark and window controls — nothing to search yet.
8. Nothing ever autoplays: no trailer previews, no next-episode countdown.

Sources: learn.microsoft.com (title bar, snap layouts, NavigationView, breakpoints, dialogs & flyouts, InfoBar, settings), Apple HIG (windows, toolbars, sidebars, full screen, playing video), GNOME HIG header bars, Tauri v2 docs, NN/g timing, MDN Media Session, RFC 8252, YouTube & Spotify shortcut pages.
